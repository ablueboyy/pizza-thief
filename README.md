# 🍕 披薩大盜 · Pizza Thief

1 個大盜 vs 最多 4 個店員的**質因數追逐戰**。手機掃 QR code 加入,大螢幕可觀戰。

## 規則

- 地圖每一格都有數字,**所有人看到的一樣**。
- 點(或滑向)相鄰的格子,再按下面的**質數按鈕** `2 3 5 7 11 13 ★`,每按一下除一次,除到剩 1 就走過去。
- **★ = 「剩下的已經是質數」**:`94` → 2 → ★(47);`97` 直接 ★。
- 按錯暈 1 秒。走過的格子數字會換新,正在拆那格的人要重來。
- 店員之間會互相擋路;大盜不能走進店員的格子。
- **店員走進大盜的格子 = 抓到,店員過關。**
- **大盜撐到時間到,或偷滿指定片數的披薩 = 大盜勝。**

### 地形

| 類型 | 例子 | |
|---|---|---|
| 兩位數、小質因數 | `12` → 2 2 3 | 好走 |
| 100~300、小質因數 | `210` → 2 3 5 7 | 要按很多下 |
| 藏大質數 / 很像質數 | `94` → 2 ★、`91` → 7 13 | 難走(按錯 ★ 會暈) |
| 兩位數質數 | `97` → ★ | 捷徑 —— 認得出來就一下過 |

### 大盜道具(三個開局都有,各用一次)

| | 道具 | 效果 |
|---|---|---|
| 🪑 | 翻桌 | 在旁邊一格放一張桌子,**永久**擋路(會把路完全堵死的位置不能放) |
| 🛵 | 外送車 | 接下來 3 步免解題 |
| 🐙 | 墨汁 | 所有店員的螢幕被噴上墨漬 6 秒 |

大盜畫面右上角的 ✕ 可以提前結束這局(不算進難度)。

## 現場怎麼用

1. 關主手機開網址 → **🦹 我是大盜(開房)**
2. 店員掃大廳的 QR code(或輸入房號)→ **👨‍🍳 當店員**
3. 大螢幕開 `網址/?screen=房號`
4. 關主按開始。結束後按「回大廳,下一組」,換人繼續

手機鎖屏或重新整理會自動接回原本的局。

## 自動難度(目標通關率 30%)

每個「店員人數」各自記一個難度值 `d`:

- 店員過關 → `d += 0.7`
- 大盜勝 → `d -= 0.3`

長期平衡點:`p × 0.7 = (1 − p) × 0.3` → **p = 30%**。

`d` 會改變:時間 `150 − 10d` 秒(60~300)、要偷的披薩 `6 − 0.5d` 片(2~12)。
大廳裡關主可以看到目前難度、近 20 場通關率,也能按 −/＋ 手動調整。
紀錄存在 `data/difficulty.json`。

> ⚠️ Render 免費方案的硬碟重新部署/休眠後會清空,難度會回到 0。
> 活動當天建議先玩幾場暖身,或直接用 −/＋ 調到你覺得對的位置。

## 跑起來

```bash
npm install
npm start                 # http://localhost:3000
MATCH_S=40 npm start      # 測試用:強制每場 40 秒
```

桌機測試:1~7 = 由左到右第幾顆按鈕、Enter/空白 = ★,方向鍵或 WASD 選格子。

## 插圖與音效

- `public/art.js`:所有插圖都是手寫 SVG(角色、披薩、道具、店裡的烤爐 / 櫃台 / 架子 / 盆栽 / 番茄箱),不用 emoji,每台手機看起來都一樣。
  地圖上的牆會依形狀自動換擺設:橫向連在一起的是櫃台,單獨一格是烤爐、架子、盆栽或番茄箱。
- `public/sfx.js`:音效全部用 Web Audio 即時合成,沒有音檔。大廳和首頁下面可以切換「音效:開/關」。
  手機要先碰一下畫面才能出聲(瀏覽器規定),所以第一次點擊之前不會有聲音。

## 調平衡

`server.js` 最上面的常數:暈眩時間、道具效果長度、地圖(`LAYOUTS`,1~2 人小地圖 9×10、3~4 人大地圖 10×11)、
地形比例(`MIX`)、`params()` 裡的時間與披薩公式。
