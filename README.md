# 🍕 披薩大盜 · Pizza Thief

1 個大盜 vs 最多 4 個店員的**質因數追逐戰**。手機掃 QR code 加入,大螢幕可觀戰。

## 規則

- 地圖每一格都有數字,**所有人看到的一樣**。
- 點相鄰的格子(上下左右),把那格數字**一次打一個質因數**拆到剩 1,就走過去。
- 打錯暈 1 秒。走過的格子數字會換新,正在拆那格的人要重來。
- 店員之間會互相擋路;大盜不能走進店員的格子。
- **店員走進大盜的格子 = 抓到,店員過關。**
- **大盜撐到時間到,或偷滿指定片數的披薩 = 大盜勝。**

### 地形

| 類型 | 例子 | |
|---|---|---|
| 兩位數合數 | `12 = 2×2×3` | 好走 |
| 三位數、小質因數 | `210 = 2×3×5×7` | 要按很多次 |
| 三位數、大質因數 | `437 = 19×23`、`143 = 11×13` | 難走 |
| 兩位數質數 | `97` | 捷徑 —— 認得出來就一下過 |

### 大盜道具(開局送 1 個,每偷一片披薩再撿 1 個,最多帶 2 個)

| | 道具 | 效果 |
|---|---|---|
| 🪑 | 翻桌 | 在 2 格內放一張桌子擋路 12 秒 |
| 🛵 | 外送車 | 接下來 3 步免解題 |
| 🌶️ | 辣椒粉 | 3 步內的店員鍵盤打亂 6 秒 |

## 現場怎麼用

1. 關主手機開網址 → **🦹 我是大盜(開房)**
2. 店員掃大廳的 QR code(或輸入房號)→ **👨‍🍳 當店員**
3. 大螢幕開 `網址/?screen=房號`
4. 關主按開始。結束後按「回大廳,下一組」,換人繼續

手機鎖屏或重新整理會自動接回原本的局。

## 自動難度(目標通關率 30%)

每個「店員人數」各自記一個難度值 `d`:

- 店員過關 → `d += 0.7`
- 大盜勝 → `d -= 0.3`

長期平衡點:`p × 0.7 = (1 − p) × 0.3` → **p = 30%**。

`d` 會改變:時間 `150 − 10d` 秒(60~300)、要偷的披薩 `6 − 0.5d` 片(2~12)。
大廳裡關主可以看到目前難度、近 20 場通關率,也能按 −/＋ 手動調整。
紀錄存在 `data/difficulty.json`。

> ⚠️ Render 免費方案的硬碟重新部署/休眠後會清空,難度會回到 0。
> 活動當天建議先玩幾場暖身,或直接用 −/＋ 調到你覺得對的位置。

## 跑起來

```bash
npm install
npm start                 # http://localhost:3000
MATCH_S=40 npm start      # 測試用:強制每場 40 秒
```

桌機測試:數字鍵 / Enter / Backspace 輸入,方向鍵或 WASD 選格子。

## 調平衡

`server.js` 最上面的常數:暈眩時間、道具效果長度、地圖(`LAYOUTS`,1~2 人小地圖 9×9、3~4 人大地圖 11×11)、
地形比例(`MIX`)、`params()` 裡的時間與披薩公式。
